# 猫鱿 (CatSquid)

一款悬浮在其他应用（比如 X）上方的猫咪宠物应用。不需要专用键盘，继续用你平时的键盘即可。只要在任意输入框里打字，宠物就会切换动画（或你添加的图片）并轻轻弹跳。你还可以把喜欢的文字（如“！”、“啊”）分配给专属图片，停止输入后会立刻回到待机动画。

工作原理：① 通过“显示在其他应用上层”权限把宠物浮在屏幕上；② 通过无障碍功能检测输入框的变化并通知宠物。通常情况下只看“有变化”这件事；当设置了“按文字切换”或显示内置的“⌫ 删除时”动画时，会在本机即时比对光标前后的输入内容（不保存、不上传，也不读取密码框）。

首次启动时会弹出语言选择（跟随系统 / 日本語 / English / 한국어 / 简体中文）。之后可随时通过设置页的“言語 / Language / 언어 / 语言”按钮修改。

## 可设置项

- **语言**：跟随系统 / 日本語 / English / 한국어 / 简体中文（首次弹窗 + 设置页按钮）
- **大小**：小 / 中 / 大 / 特大
- **晃动强度**：无（只切换图片）到 3 档
- **始终置顶**：开启后打开其他应用时自动显示；关闭时只手动显示
- **位置锁定**：开启后点击穿透到下层应用，也不能拖动
- **重置位置**
- **传感器互动**：倾斜手机时，宠物会朝重力方向轻轻滑动并歪头。可以设置倾斜灵敏度（低/中/高）。只有在宠物显示且屏幕亮起时才读取传感器。
- **角色保存**：按角色保存一整套图片 + 内置颜色，可命名和切换
- **多角色显示**：可以同时显示任意多个已保存角色。点击上方的“显示的角色”图标切换显示/隐藏，屏幕上可分别拖动
- **内置猫咪动画**：没有注册任何图片时，使用待机、输入、删除的 GIF 动画。输入 `!`、`?`、空格时会使用专用动画（`exclamation.gif` / `question.gif` / `space.gif`）；找不到对应动画时回到待机。
- **内置 4 种颜色**（给内置猫咪动画着色）
- **图片分 3 类注册（数量不限）**
  - **待机**：未输入时显示。注册多张后，每次回到待机都会随机选一张
  - **输入中（按顺序）**：第 1 张 → 第 2 张 → … 依次切换。每个编号可以添加不同图案，该编号会随机选一张
  - **按文字切换（可选）**：注册喜欢的文字后，输入该文字的瞬间会从对应图片中随机显示一张。一张图片可以分配多个文字（例如“啊”“呜”对应同一个表情）
  - 停止输入后回到待机，下次从第 1 张开始。一张图片都没有时使用内置猫咪动画
- **主屏幕图标（可选）**：选择喜欢的图片，作为快捷方式添加到主屏幕（见下文“关于图标”）。

## 关于图标

应用本身的默认图标是猫鱿的猫咪图标。由于 Android 的限制，安装后无法更改应用本身的图标；如果想换成其他图片，可以在设置页的“更改主屏幕图标”中选择图片，系统会用该图片创建一个快捷方式。以后请通过该快捷方式打开应用（原图标仍会留在应用列表中）。

## 版本

- 版本号由 `version.properties` 管理。
- 构建前请执行 `python3 scripts/bump_version.py`，它会把 `versionCode` +1、`versionName` 的最后一位 +1。
- `app/build.gradle` 和手动构建都会读取这个文件。

## Release 构建

- 本地构建的 release APK 位于 `app/build/outputs/apk/release/app-release.apk`。
- 想复制到更短的路径，运行 `sh scripts/package_apk.sh`（生成 `dist/catsquid-<version>.apk`）。
- 使用 `app/typingpet-release.jks`（alias：`typingpet`）签名。不要把密钥提交到仓库。

## 在 GitHub 上构建（不需要 Android Studio）

1. 把整个文件夹（包括 `.github` 等隐藏目录）push 到新的 GitHub 仓库。
2. 打开 **Actions** 标签，`Build APK` 会自动运行（也可以点 `Run workflow` 手动触发）。
3. 完成后在结果页面的 **Artifacts** 下载 `catsquid-debug-apk`，解压得到 `app-debug.apk`。

## 在手机上使用

1. 把 `app-debug.apk` 传到手机并安装（首次需要允许“安装未知来源应用”）。
2. 首次启动选择语言。
3. ①“允许显示在其他应用上层” → 在设置中开启。
4. ②“打开无障碍设置” → 在列表中找到“猫鱿”并开启（会出现 Android 标准警告，但除了上面的文字比对外不会做任何事）。
5. ③ 点击“显示宠物”。
6. 在“预设”标签选择喜欢的颜色，或在“插画”标签添加自己的图片。“按文字切换”也在这里设置。
7. 在 X 等任意应用里打字，宠物就会反应。拖动可以改变位置。

## 项目结构

- `Prefs.kt`：保存/读取所有设置（包括语言、！/？专属图片 URI）
- `LocaleHelper.kt`：把选择的语言应用到 Activity
- `MainActivity.kt`：设置界面（首次语言弹窗、权限按钮 + 基本/预设/插画三个标签、主屏幕图标快捷方式，全部用代码构建）
- `PetView.kt`：绘制宠物（显示注册图片、播放内置猫咪 GIF、软弹动画）
- `ImageLoader.kt`：把注册图片缩小到所需尺寸后加载
- `OverlayService.kt`：把宠物悬浮在屏幕上；实时应用设置；根据屏幕亮灭启停传感器
- `MotionController.kt`：从加速度传感器计算设备倾斜
- `PetAccessibilityService.kt`：检测其他应用的输入；启用“按文字切换”或内置“⌫ 删除时”时，在本机比对光标前后的内容
- `res/values/strings.xml`、`res/values-en/strings.xml`、`res/values-ko/strings.xml`、`res/values-zh/strings.xml`：日/英/韩/简中文本
- `res/raw/*.gif`：内置猫咪动画（待机 / 输入 / 删除 / `!` `?` 空格专用；`question.gif` 可缺省）
- `res/mipmap-*/ic_launcher.png`、`ic_launcher_round.png`：传统应用图标
- `res/mipmap-anydpi-v26/ic_launcher*.xml`、`res/drawable-xxxhdpi/ic_launcher_foreground.png`：Android 8+ 自适应图标
- `version.properties`、`scripts/bump_version.py`：版本管理与构建前自增
- `AGENTS.md`：构建与版本规则
