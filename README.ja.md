# 猫鱿 (CatSquid)

Xなど他のアプリの上にフワッと浮かぶ、ネコのペットのオーバーレイアプリです。専用キーボードは不要で、普段使っているキーボードのままで大丈夫です。どこかの入力欄に文字を打つたびに、ペットのアニメ(または追加した自分のイラスト)が切り替わってちょこっと跳ねます。好きな文字(「！」「あ」など)を専用イラストに割り当てることもでき、入力が止まるとすぐに待機アニメに自動で戻ります。

仕組み：①「他のアプリの上に表示」権限で画面にペットを浮かせ、②アクセシビリティ機能でどこかの入力欄が変化したことを検知してペットに知らせています。基本的には変化があったことだけを見ますが、内蔵の `!` `?` 空白アニメを出すために直前に挿入された文字も読みます。「文字で切り替え」を設定している場合と、内蔵アニメの「⌫ 消したとき」を出す場合は、入力内容の前後関係をその場で照合します（保存・送信は一切せず、パスワード欄は見ません）。

初回起動時に言語(日本語/English/한국어/简体中文/端末の言語)を選ぶポップアップが出ます。設定画面の「言語 / Language / 언어 / 语言」ボタンからいつでも変更できます。

## 設定できること

- **言語**：端末の言語 / 日本語 / English / 한국어 / 简体中文(初回ポップアップ＋設定画面のボタンでいつでも変更可)
- **サイズ**：小 / 中 / 大 / 特大
- **揺れの強さ**：なし(画像だけ切り替え) 〜 3段階
- **起動時に自動で表示**：ONなら端末を再起動しても自動で戻ります。OFFなら再起動後に③ボタンで表示します。通知の「停止」でいつでも止められます。
- **位置ロック**：ONでタップが下のアプリに素通りし、ドラッグ移動も不可に
- **位置の初期化**
- **バックアップと復元**：キャラ・画像・設定を zip に書き出し／復元。復元すると今のデータは上書きされます。
- **センサー連動**：スマホを傾けるとペットが重力方向へ少し滑って首をかしげます。傾きの感度（スライダー、0〜100%）を設定できます。センサーはペット表示中かつ画面オンのときだけ動きます。
- **キャラ保存**：イラスト一式＋内蔵カラーをキャラごとに名前を付けて保存し、切り替え可能
- **複数キャラ表示**：保存したキャラを何体でも同時に画面に出せる。上の「表示するキャラ」アイコンをタップで表示／非表示、画面上ではキャラごとにドラッグで移動
- **内蔵ネコアニメ**：画像を1枚も登録していないときは、待機・入力・削除のGIFアニメで動く。`!` `?` 空白には専用アニメ（`exclamation.gif` / `question.gif` / `space.gif`）を使い、見つからない場合は待機に戻る。入力ステップの画像を登録している場合は、そちらが優先される。
- **内蔵カラー4色**から選択（内蔵ネコアニメを着色）
- **イラストは3種類に分けて登録(枚数無制限)**
  - **待機**：入力していない時に表示。複数登録すると待機に戻るたびにランダムで1枚
  - **タイピング中(順番)**：1番目→2番目→…の順に切り替え。各番号に別パターンを追加でき、その番号ではランダムで1枚
  - **文字で切り替え(任意)**：好きな文字を登録すると、入力した瞬間にその画像からランダムで1枚。1つのイラストに複数の文字を割り当て可能(例：「あ」「う」でどよーん)
  - 入力が止まると待機に戻り、次は1番目から。画像が1枚もなければ内蔵ネコアニメで動作
- **ホーム画面のアイコンを変更(任意)**：好きな画像を選んでホーム画面にショートカットとして追加できます(下記「アイコンについて」を参照)。

## アイコンについて

アプリ本体のアイコンはデフォルトで猫鱿のネコアイコンになっています。Androidの仕組み上、インストール後にアプリ本体のアイコン画像を書き換えることはできないため、「好きな画像に変えたい」場合は設定画面の「ホーム画面のアイコンを変更」から画像を選ぶと、その画像を使ったショートカットをホーム画面に追加できます。今後はそのショートカットからアプリを開いてください（元のアイコンはアプリ一覧に残ります）。

## バージョンについて

- バージョンは `version.properties` で管理します。
- ビルド前に `python3 scripts/bump_version.py` を実行してください。`versionCode` が +1、`versionName` のパッチが +1 されます。
- `app/build.gradle` と手動ビルドの両方がこのファイルを参照します。

## リリースビルド

- ローカルの release APK は `app/build/outputs/apk/release/app-release.apk` です。
- 配布用に短いパスへコピーするには `sh scripts/package_apk.sh` を実行します（`dist/catsquid-<version>.apk`）。
- 署名には `app/typingpet-release.jks`（alias: `typingpet`）を使います。鍵はリポジトリに含めないでください。

## GitHubでビルドする（Android Studio不要）

1. このフォルダの中身をGitHubの新規リポジトリにそのままpushします（`.github` などの隠しフォルダも含めてください）。
2. **Actions** タブを開くと `Build APK` が自動で走ります（手動で走らせたい場合は `Run workflow`）。
3. 完了したら実行結果ページ下部の **Artifacts** から `catsquid-debug-apk` をダウンロードし、zipを展開して `app-debug.apk` を取り出します。

## スマホでの使い方

1. `app-debug.apk` をスマホに転送してインストール（初回は「提供元不明のアプリ」許可が必要）。
2. 初回起動時に言語を選択。
3. ①「他のアプリの上に表示を許可」→ 設定でON。
4. ②「アクセシビリティ設定を開く」→ 一覧から「猫鱿」をON（Android標準の警告文が出ますが、上記の文字照合以外は何もしません）。
5. ③「ペットを表示する」をタップ。
6. 「プリセット」タブで好きな色を選ぶか、「イラスト」タブで自分の画像を追加。「文字で切り替え」もここから設定できます。
7. Xなど好きなアプリで文字を打つと、ペットが反応します。ドラッグで位置も変えられます。

## 中身について

- `Prefs.kt` : すべての設定の保存・読み込み（言語設定、！／？専用イラストのURIも含む）
- `LocaleHelper.kt` : 選んだ言語をActivityに適用するヘルパー
- `MainActivity.kt` : 設定画面（初回言語ポップアップ、権限ボタン＋基本設定/プリセット/イラストの3タブ、ホーム画面アイコン追加、すべてコードで組み立て）
- `PetView.kt` : ペットを描画（登録画像の表示、内蔵ネコGIFアニメの再生、もちもちアニメ）
- `ImageLoader.kt` : 登録画像を必要なサイズに縮小して読み込む
- `OverlayService.kt` : ペットを画面上に浮かせて表示。設定変更をリアルタイム反映。画面オン/オフに合わせてセンサーを開始・停止
- `MotionController.kt` : 加速度センサーの傾きとジャイロの角速度を相補フィルターで合成し、反応を速く滑らかにする
- `PetAccessibilityService.kt` : 他アプリでの入力を検知してペットに知らせる。「文字で切り替え」または内蔵アニメの「⌫ 消したとき」が有効な場合、入力内容の前後関係をその場で照合する
- `ImeWindowWatcher.kt` : イベントを送らない入力法（搜狗・百度など）向けに、キーボードウィンドウの候補欄を定期的に読んでキー入力を検出する
- `res/values/strings.xml`, `res/values-en/strings.xml`, `res/values-ko/strings.xml`, `res/values-zh/strings.xml` : 日本語・英語・韓国語・簡体字中国語の文言
- `res/raw/*.gif` : 内蔵ネコアニメ（待機 / 入力 / 削除 / ! ? 空白の専用。`question.gif` は無くても可）
- `res/mipmap-*/ic_launcher.png`, `ic_launcher_round.png` : 従来型のアプリアイコン
- `res/mipmap-anydpi-v26/ic_launcher*.xml`, `res/drawable-xxxhdpi/ic_launcher_foreground.png` : Android 8+ 用のアダプティブアイコン
- `version.properties`, `scripts/bump_version.py` : バージョン管理とビルド前の自動インクリメント
- `AGENTS.md` : ビルドとバージョンの運用ルール
