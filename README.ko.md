# 猫鱿 (CatSquid)

X 등 다른 앱 위에 살짝 떠오르는 고양이 펫 오버레이 앱입니다. 전용 키보드는 필요 없고, 평소 쓰던 키보드를 그대로 사용하면 됩니다. 어딘가의 입력창에 글자를 입력할 때마다 펫의 애니메이션(또는 추가한 내 이미지)이 바뀌고 살짝 튀어 오릅니다. 좋아하는 문자("!", "あ" 등)를 전용 이미지에 할당할 수 있고, 입력이 멈추면 바로 대기 애니메이션으로 돌아갑니다.

작동 방식: ① "다른 앱 위에 표시" 권한으로 화면에 펫을 띄우고, ② 접근성 기능으로 어딘가의 입력창이 변한 것을 감지해 펫에게 알립니다. 기본적으로는 변화가 있었다는 것만 보지만, "문자로 전환"을 설정했거나 내장 애니메이션의 "⌫ 지울 때"를 표시하는 경우에는 입력 내용의 앞뒤를 그 자리에서 비교합니다(저장·전송하지 않으며 비밀번호 입력란은 보지 않습니다).

첫 실행 시 언어(기기 언어 / 日本語 / English / 한국어 / 简体中文)를 선택하는 팝업이 나옵니다. 설정 화면의 "言語 / Language / 언어 / 语言" 버튼에서 언제든지 변경할 수 있습니다.

## 설정 항목

- **언어**: 기기 언어 / 日本語 / English / 한국어 / 简体中文 (첫 실행 팝업 + 설정 버튼)
- **크기**: 작게 / 보통 / 크게 / 아주 크게
- **흔들림 강도**: 없음(이미지만 전환) ~ 3단계
- **항상 맨 위에 고정**: ON이면 다른 앱을 열 때 자동 표시, OFF면 수동 표시만
- **위치 잠금**: ON이면 터치가 아래 앱으로 통과되고 드래그 이동도 불가
- **위치 초기화**
- **센서 연동**: 스마트폰을 기울이면 펫이 중력 방향으로 살짝 미끄러지고 고개를 갸웃합니다. 기울기 감도(낮음/보통/높음)를 설정할 수 있습니다. 센서는 펫이 표시 중이고 화면이 켜져 있을 때만 동작합니다.
- **캐릭터 저장**: 이미지 세트 + 내장 색상을 캐릭터별로 이름을 붙여 저장하고 전환 가능
- **여러 캐릭터 표시**: 저장한 캐릭터를 여러 개 동시에 화면에 표시. 위의 "표시할 캐릭터" 아이콘을 탭해 표시/숨기기, 화면에서는 캐릭터별로 드래그 이동
- **내장 고양이 애니메이션**: 이미지를 하나도 등록하지 않았을 때 대기·입력·삭제 GIF 애니메이션으로 동작합니다. `!`, `?`, 공백에는 전용 애니메이션(`exclamation.gif` / `question.gif` / `space.gif`)을 사용하고, 없으면 대기로 돌아갑니다.
- **내장 색상 4색** 선택(내장 고양이 애니메이션에 색을 입힘)
- **이미지는 3종류로 등록(개수 제한 없음)**
  - **대기**: 입력하지 않을 때 표시. 여러 장 등록하면 대기로 돌아올 때마다 무작위로 1장
  - **타이핑 중(순서)**: 1번째 → 2번째 → … 순서로 전환. 각 번호에 다른 패턴을 추가할 수 있고, 그 번호에서는 무작위로 1장
  - **문자로 전환(선택)**: 좋아하는 문자를 등록하면 입력하는 순간 그 이미지에서 무작위로 1장. 하나의 이미지에 여러 문자를 할당 가능(예: "あ", "う"로 우울한 표정)
  - 입력이 멈추면 대기로 돌아가고 다음에는 1번째부터. 이미지가 하나도 없으면 내장 고양이 애니메이션으로 동작
- **홈 화면 아이콘 변경(선택)**: 좋아하는 이미지를 골라 홈 화면에 바로가기로 추가할 수 있습니다(아래 "아이콘에 대하여" 참조).

## 아이콘에 대하여

앱 본체의 아이콘은 기본으로 고양이(猫鱿) 아이콘입니다. Android 특성상 설치 후 앱 본체의 아이콘 이미지를 바꿀 수 없으므로, 다른 이미지로 바꾸고 싶다면 설정 화면의 "홈 화면 아이콘 변경"에서 이미지를 고르면 그 이미지를 사용한 바로가기가 홈 화면에 추가됩니다. 앞으로는 그 바로가기에서 앱을 열어 주세요(원래 아이콘은 앱 목록에 남습니다).

## 버전

- 버전은 `version.properties`에서 관리합니다.
- 빌드 전에 `python3 scripts/bump_version.py`를 실행하세요. `versionCode`가 +1, `versionName`의 패치가 +1 됩니다.
- `app/build.gradle`과 수동 빌드 모두 이 파일을 참조합니다.

## 릴리스 빌드

- 로컬에서 빌드한 release APK는 `app/build/outputs/apk/release/app-release.apk`입니다.
- 배포용 짧은 경로로 복사하려면 `sh scripts/package_apk.sh`를 실행하세요(`dist/catsquid-<version>.apk`).
- 서명에는 `app/typingpet-release.jks`(alias: `typingpet`)를 사용합니다. 키는 저장소에 커밋하지 마세요.

## GitHub에서 빌드(Android Studio 불필요)

1. 이 폴더를 새 GitHub 저장소에 그대로 push합니다(`.github` 같은 숨김 폴더도 포함).
2. **Actions** 탭을 열면 `Build APK`가 자동으로 실행됩니다(수동 실행은 `Run workflow`).
3. 완료되면 결과 페이지 아래 **Artifacts**에서 `catsquid-debug-apk`를 다운로드하고 zip을 풀어 `app-debug.apk`를 꺼냅니다.

## 스마트폰에서 사용

1. `app-debug.apk`를 스마트폰으로 옮겨 설치(첫 설치 시 "출처를 알 수 없는 앱" 허용 필요).
2. 첫 실행 시 언어 선택.
3. ① "다른 앱 위에 표시 허용" → 설정에서 ON.
4. ② "접근성 설정 열기" → 목록에서 "猫鱿"를 ON(Android 표준 경고가 나오지만, 위의 문자 비교 외에는 아무것도 하지 않습니다).
5. ③ "펫 표시"를 탭.
6. "프리셋" 탭에서 색을 고르거나 "이미지" 탭에서 내 이미지를 추가. "문자로 전환"도 여기서 설정.
7. X 등 좋아하는 앱에서 글자를 입력하면 펫이 반응합니다. 드래그로 위치도 바꿀 수 있습니다.

## 구성

- `Prefs.kt`: 모든 설정 저장/불러오기(언어, !/? 전용 이미지 URI 포함)
- `LocaleHelper.kt`: 선택한 언어를 Activity에 적용
- `MainActivity.kt`: 설정 화면(첫 언어 팝업, 권한 버튼 + 기본/프리셋/이미지 3탭, 홈 화면 아이콘 추가, 모두 코드로 구성)
- `PetView.kt`: 펫 그리기(등록 이미지, 내장 고양이 GIF, 말랑말랑 애니메이션)
- `ImageLoader.kt`: 등록 이미지를 필요한 크기로 축소해 로드
- `OverlayService.kt`: 펫을 화면에 띄움. 설정 변경 실시간 반영. 화면 켜짐/꺼짐에 맞춰 센서 시작/정지
- `MotionController.kt`: 가속도 센서로 기기 기울기 계산
- `PetAccessibilityService.kt`: 다른 앱 입력 감지. "문자로 전환" 또는 내장 "⌫ 지울 때"가 켜져 있으면 입력 앞뒤를 그 자리에서 비교
- `res/values/strings.xml`, `res/values-en/strings.xml`, `res/values-ko/strings.xml`, `res/values-zh/strings.xml`: 일본어·영어·한국어·중국어 간체 문구
- `res/raw/*.gif`: 내장 고양이 애니메이션(대기 / 입력 / 삭제 / `!` `?` 공백 전용. `question.gif`는 없어도 됨)
- `res/mipmap-*/ic_launcher.png`, `ic_launcher_round.png`: 기존형 앱 아이콘
- `res/mipmap-anydpi-v26/ic_launcher*.xml`, `res/drawable-xxxhdpi/ic_launcher_foreground.png`: Android 8+ 적응형 아이콘
- `version.properties`, `scripts/bump_version.py`: 버전 관리와 빌드 전 자동 증가
- `AGENTS.md`: 빌드와 버전 운용 규칙
